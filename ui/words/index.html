Eight words.

Give EmbeddingGemma 2 a photo, a sound, a sentence, or all three. It turns them into one point: 768 numbers. This page writes that point back as up to eight ordinary words, chosen one at a time so that when the model reads the words, it lands on the same point.

Three simple examples. Click one to run it live.

Nobody wrote these words. Each is a token from the model's own vocabulary of 262,144, picked because, read together, they land closest to the point, and kept only if dropping it would move the reading away. It is a lossy codec, like JPEG for meaning: eight words are 144 bits where the point is 12,288. Sentences come out clean; photos and sounds come out rougher, because the model's idea of a cow is not made of words. Either way, type the words into any search box that uses the model and the same results come back.
